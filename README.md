# API REST apipersonal 🚀

API REST desarrollada con Node.js, Express y MySQL bajo el patrón de arquitectura MVC (Modelo-Vista-Controlador), orientada a la gestión de un e-commerce de joyería y accesorios personalizados.

## 📌 Información General
* **Autor:** Rafael Isaías Arzuza Verdeza
* **Tecnologías:** Node.js, Express.js, MySQL, dotenv, cors
* **Repositorio GitHub:** [Rafael777-RP/apipersonal](https://github.com/Rafael777-RP/apipersonal)
* **Despliegue Cloud:** [Render Web Service](https://apipersonal-qes7.onrender.com/)

---
